# Kubernetes Triage Agent — presentation site

A short, LinkedIn-friendly walkthrough of the Kubernetes Triage Agent architecture: three node lanes, read-only guardrails, and the self-host vs API cost story.

## Run locally

```bash
cd web
npm install
npm run dev
```

Opens on [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run build
npm run preview
```
